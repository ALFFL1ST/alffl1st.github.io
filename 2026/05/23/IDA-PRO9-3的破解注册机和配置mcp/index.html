IDA PRO9.3的破解注册机和配置mcp

发表于 2026-05-23

现在新版本的ida pro已经自带mcp相关配置了，用ai一把唆的感觉真是爽翻了，话不多说直接开始配置

0.资源准备

【全平台】IDA Pro 9.3 正式版泄露版+注册机：[分享]【全平台】IDA Pro 9.3 正式版泄露版+注册机-安全工具-看雪安全社区｜专业技术交流与安全研究论坛

cherry studio：https://github.com/CherryHQ/cherry-studio

1.IDA pro注册机破解

在看雪上下载的安装包解压后会是这样，在installers文件夹中找到自己系统的版本，先把正式版安装上

注册机在这个文件夹下，选择自己的系统解压

我这里用的是windows系统，就这样演示一下

用管理员权限打开这个exe

输入以下命令生成个人版许可证（Named）：

ida_keygen_v2.exe -u “你的用户名” -e “任意邮箱” -t Named

注意：-u 后面是你想要的名字，-e 随便填个邮箱格式即可，-t Named 代表个人版。
执行后，会在同目录生成一个 .hexlic 文件

想使用这个hexlic注册，ida.dll文件就需要修复，用任何一个可以修改二进制的工具都可以操作，我这里用Ultra Edit演示

打开后查找：ED FD 42 5C,搜出的第一个结果就是我们需要修改的地方，然后把这个5c改为cb，改完之后保存

接下去启动 IDA Pro
进入 License manager
选择 “Use local idapro.hexlic file”*
浏览并选中第一步生成的 .hexlic 文件
点击 OK

到这里没有报错就正常注册了，可以打开ida后点击help 选择help，如果正常显示注册信息，那就是大功告成了

2.cherry studio配置ai

打开设置，把供应商深度求索都打开，输入api密钥获取模型（获取api的方法在上一篇博客）

在这试着选择deepseek，说几句话，确定ai已经连上了

3.配置mcp

打开ida，选择edit->plugins->mcp

当ida的命令行出现这个提示时说明mcp的端口已经打开了，在cherry studio的文本框这这么点，选择手动mcp配置

这边可以使用ai直接写一份ida的mcp的配置，复制进去就搞定

到这一步来说，软件内的配置已经算好了

4.补充python环境

想要ida正常调用mcp相关的工具，需要python版本在3.11以上，本人使用的是3.12版本的，关于python的下载安装这就不做过多演示了，把python相关的文件夹放入环境变量path中（安装时可选）之后，输入：

pip install https://github.com/mrexodia/ida-pro-mcp/archive/refs/heads/main.zip

其实这个链接就是github上idapromcp的开源项目，集成了很多工具供ai调用

全部安装完之后，，打开ida在后台，用deepseek连接，就可以体验一把梭的爽感了
